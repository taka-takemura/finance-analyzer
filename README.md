# 財務分析ビジュアライザー

数年分の財務諸表 (Excel/CSV) をアップロードするだけで、チャート生成・ROICツリー・DuPont分析・CVP分析・感応度シミュレーションを行える Streamlit アプリです。

## セットアップ

```bash
cd finance-analyzer
pip install -r requirements.txt
python create_template.py   # テンプレート.xlsx / サンプルデータ.xlsx を生成
streamlit run app.py
```

ブラウザで http://localhost:8501 が開きます。

## 使い方

1. サイドバーの「データソース」から選択: ファイルアップロード / サンプルデータ / EDINETから自動取得
2. ファイルの場合は自作テンプレートまたはSPEEDAエクスポートをアップロード
3. 全タブ (チャート・各種分析・シミュレーション) が自動生成されます

## 対応データソース

### 1. ファイルアップロード
- **自作テンプレート (Excel)**: シート名 `PL`/`BS`/`CF` (損益計算書・貸借対照表などの和名、Income Statement 等の英名も可)
- **SPEEDAエクスポート**: 「三表一括(PL・BS・CF)」「財務諸表サマリー」をそのままアップロードすると自動認識 (最大20年超の長期データに対応、分析対象期間はサイドバーで絞り込み可)
- **CSV**: 1列目に `区分` (PL/BS/CF)、2列目に科目、3列目以降に年度
- 科目名は日本基準・IFRS・US GAAP のエイリアスを自動認識 (例: 売上収益 / Revenue / Net sales → 売上高)
- 小計 (売上総利益、資産合計など) が欠けていても構成科目から自動補完

### 2. EDINET自動取得
証券コードを入力するだけで、有価証券報告書のXBRLデータから自動転記します。

1. https://api.edinet-fsa.go.jp/ でAPIキーを無料発行 (メール登録のみ)
2. サイドバーで「EDINETから自動取得」を選択し、APIキー・証券コード・取得年数を入力
3. 「EDINETから取得」ボタンで自動取得 (単位は百万円に換算)

注意点:
- EDINETの書類一覧APIは日付単位のため、提出日の走査に初回1〜3分かかります
- XBRL科目のマッピングは主要科目のベストエフォートです。IFRS採用企業は科目体系が異なるため一部欠損することがあります (欠損分は自動補完)
- 有報1件に当期+前期が含まれるため、期数は指定年数+1になることがあります

## 機能

| タブ | 内容 |
|---|---|
| ダッシュボード | バフェットコード風の指標カードグリッド (値+前年差+年次ミニチャート)。株価・株式数を入力すると時価総額・PER・PBR・EPS・BPS・配当利回りも表示 (株価はYahoo Finance/Stooqから自動取得を試行、失敗時は手入力) |
| 概要 | KPIカード (前年比つき)、売上・利益推移、利益率、CF、資産構成 |
| 財務指標 | 収益性・効率性・安全性・成長性・CFの指標一覧と推移チャート |
| DuPont分析 | ROE 3分解ツリー、要素の推移、対前年のROE要因分解ウォーターフォール |
| ROICツリー | ROIC = 営業利益率 × 投下資本回転率 × (1−税率) のツリー展開、WACC比較 |
| CVP分析 | 高低点法による変動費率推定、損益分岐点チャート、安全余裕率 |
| シミュレーション | 売上・原価率・販管費・回転期間・有利子負債のスライダー調整 → PL/ROE/ROICへの影響、営業利益ブリッジ、トルネードチャート |

## 計算上の前提

- 残高 (総資産・自己資本など) は期末値ベース
- ROE・DuPont・財務レバレッジ・自己資本比率・D/Eの分母は**自己資本 (親会社株主帰属分)** を使用。分子の当期純利益 (親会社株主帰属) と整合させるため。「自己資本」または「非支配株主持分」が入力されていない場合は純資産合計で代用
- ROIC = 営業利益 × (1−実効税率) ÷ (純資産合計 + 有利子負債)。投下資本は非支配株主持分込み。実効税率はサイドバーで調整可
- CVPの変動費率は高低点法で初期推定し、スライダーで上書き可能
- シミュレーションは簡易モデル (営業外費用は有利子負債に比例と仮定) です
